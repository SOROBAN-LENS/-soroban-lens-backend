# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. All contributors, maintainers, and participants are
expected to follow it in every project space: issues, pull requests,
discussions, and any other community channels.

## In short

* Be respectful and constructive; assume good intent.
* Welcome newcomers; questions about Stellar and Soroban are always on-topic.
* No harassment, discrimination, personal attacks, or publishing others'
  private information.
